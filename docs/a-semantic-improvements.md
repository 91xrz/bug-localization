# A 原报告语义检索：分层改进实验

研究发起于 2026-11-22。正式运行：`results/a_improvements/20261122_v3/`。

本实验单独改进 A（S0）：原始报告正文 → Qwen3-Embedding-0.6B → AST64 → 文件 Max。它不使用 B 的功能推测，也没有将改进后的 A 接入当前 `ab_structure_v1` 或 C 重排。历史 A 和现行组合基线保持原有定义。

## 结论与采用建议

**A 有明确的轻量改进空间，建议保留 AST64 编码与切块主体，增加结构匹配，并可配合弱聚合；不推荐本轮的块数惩罚和受限向量反馈。**

全部 2,294 条已完成，无失败。主实验比较 43 种增强设置与 A 对照，在原 500 条筛选，随后冻结各家族赢家，在其余 1,794 条复核。另完成 20 次开发集划分、9 次开发项目留出、4 项机制消融和一个召回目标对照。主实验 32,764 份排名指标独立复算通过；补充实验的对照排名也逐条核对通过。

- **最小改动**：原 A50 内加入原报告函数名、类名和路径证据，权重 0.5。验证 MAP 从 0.510525 到 0.597312；候选集合严格不变，因此 Recall@50 也严格不变。
- **以前排精度为目标的主方案**：文件相似度先用 `S=0.75*Max+0.25*Top3Mean`，按 S 取50；在该池内用 `N(S)+0.5*E` 排序。验证 MAP 为 0.603689，MRR 为 0.670332，Top-1 从 39.46% 到 55.07%。结构匹配是主要收益来源。
- **偏召回的可选方案**：原 A200 内结构匹配，再保留50。验证 MeanRecall@50 从 0.921013 到 0.928044，MAP 为 0.590288。它没有在前排精度上胜过主方案，不能混用两者的最好指标。
- **暂不采用**：块数惩罚使多个指标下降；受限反馈 MAP 只增加 0.001119，95% 区间跨0，且项目宏平均为负。

当前证据支持的是**这批历史 Python/SWE 语料上的稳定平均收益**。没有新生成、Embedding 或 Reranker 调用，也没有修改默认检索配置。已采用的 A+B 基线 `ab_structure_v1` 保持原样：它在全2,294条的 MAP 为 0.621854，高于本次 A 主方案的 0.598472。A 增强接入 A+B/C 后能否继续增益尚未验证，尤其不能直接重复叠加已有的结构分数。

全2,294条：原 A 的 MAP/MRR 为 **0.507576/0.561667**，主方案为 **0.598472/0.664716**。这一全量汇总包含参与调参的500条；评价稳定性优先看上表剩余1,794条。

主方案相对 A 的复核结果：

- ΔMAP = **+0.093164**，项目分层配对 bootstrap 95% 区间 **[+0.082714, +0.103733]**；将召回对照纳入后的30项 Holm 校正 p = **0.005999**。
- 逐报告 AP：**630胜 / 990平 / 174负**。12项目中10个平均提升；项目宏平均 ΔMAP = **+0.063608**。去掉任一项目后整体提升仍在 **+0.086351 至 +0.096807**。
- 去掉最大10个收益样本后 ΔMAP 仍为 **+0.088759**；排除与开发集重复的正文并在验证内去重，剩余1,775条 ΔMAP 为 **+0.093833**，95%区间 **[+0.083001, +0.104360]**。
- 20次开发集70/30划分，每次只用训练部分选参数，测试部分全部提升，ΔMAP 范围 **+0.042403 至 +0.103763**；9次开发项目留出也全部为正。这是选择流程的敏感性检查，不是20次独立盲测。
- 相对仅结构匹配，主方案额外 ΔMAP 为 **+0.006377**，描述性95%区间 **[+0.002308, +0.010516]**。这项增量比较没有纳入原主检验族；同时其 Hit@10 比仅结构匹配少命中1条，不能声称所有指标都更好。
- 主方案 MeanRecall@50 的增量区间跨0，**没有证据称其显著提高Top50召回**。召回对照的 MeanRecall@50 增量 **+0.007031**，95%区间 **[+0.002708, +0.011506]**，30项 Holm p = **0.034193**；其 Hit@50 校正 p = 0.071986，不作显著改善声明。

边界必须保留：Flask 的11条平均 ΔMAP = **−0.032816**；pylint 仅1条复核样本，ΔMAP = −0.033333，不能代表项目总体。本轮未参与调参的三个项目合计77条 ΔMAP = +0.029297，但95%区间 **[−0.020754, +0.078527]**，**尚不足以证明向新项目稳定迁移**。整个语料之前已经观察过，本研究不是独立盲测，统计结果也不应包装成对新数据的泛化保证。

## 机制消融结果

| 同一弱聚合候选池上的消融 | 复核 MAP@10 |
|---|---:|
| 仅弱聚合，不加结构 | 0.520829 |
| 仅路径/模块证据 | 0.555321 |
| 仅标识符证据 | 0.584024 |
| 结构匹配仅看实际编码的报告片段 | 0.597942 |
| 完整正文＋全部结构证据 | 0.603689 |

这组保持候选池、聚合和结构权重相同。完整结构证据相对仅弱聚合增加 **0.082860 MAP**，说明主要增益确实来自结构匹配；只看实际编码片段仍达到0.597942，说明不是单纯补读报告尾部。读取完整正文额外增加0.005746，路径/模块与标识符均提供互补信息。完整方案对四个消融的 MAP 差值95%区间都在0以上，四项 Holm p 均为0.000800。

## 由易到难的改动

| 层级 | 模块 | 预设变体 | 计算与边界 |
|---|---|---|---|
| 1 | 文件分数聚合 | Top-2/3 mean；Max 与 Top-3 均值混合权重 0.25/0.5；归一化 LSE 温度 0.02/0.05/0.1 | 复用全部代码块分数；候选全集不变 |
| 1 | 大文件偏置校正 | `max - penalty*log(chunk_count)`；penalty 0.002/0.005/0.01 | 检查较多代码块是否给大文件带来偶然高分 |
| 2 | 原报告结构匹配 | A 的前 50/200 个文件；权重 0.1/0.25/0.5/1 | 修复前源码函数/类声明和文件路径；始终输出最多 50 个文件 |
| 3 | 受限向量伪相关反馈 | 前 1/3/5 文件反馈；beta 0.1/0.25/0.5 | 使用每个文件原查询下的最佳块，重排原 A50；不是全库二次召回 |
| 3 | 组合消融 | 固定弱聚合或弱长度校正，分别搭配各结构匹配设置 | 检验多加模块是否比单独结构匹配更有价值 |

合计 **43 个改进设置＋1 个 A 对照**。重复运行相同确定性流程不会产生有意义的随机重复，因此通过参数变体、冻结验证、20 次开发集划分和跨项目检查考察稳定性。

结构分数 `E` 复用既有 `lightweight_hypothesis.anchors` 的规则，但候选只来自 A：对原报告与源码声明的精确标识符匹配做 IDF 加权覆盖率，显式相对路径/模块名命中时置 1。去掉报告 HTML 注释及 URL，忽略通用内置名称。词表和 IDF 独立在当前 A50/A200 内计算，不使用 A+B 联合池。

对语义得分 `s` 做 `N(s)=clip((s-s50)/(s1-s50),0,1)`；同分时归零。结构路线使用 `N(s)+lambda*E`，按分数、原排名、路径排序。前 50 内重排不能提高 Recall@50；前 200 的设置才有机会改变最终 50 个文件的覆盖。

反馈使用 `q'=normalize((1-beta)*q + beta*mean(v1..vk))`，随后比较 `q'` 与 A50 中每个文件原始最佳块向量。它可以检查查询漂移，但不能代表重新搜索全部代码块的完整 PRF，也不能据此否定所有反馈方法。

## 数据与冻结协议

- 同一全量来源 `results/recall_full/20261118_swe2294_v2`：2,294 条、12 项目。
- 原有 500 条用于选参数；剩余 1,794 条在选择文件落盘后才评测冻结设置。
- 两组属于历史已观察语料，后组不是独立盲测，也不构成跨数据集泛化证明。
- 每个家族选开发集 MAP 最高者用于诊断；推荐资格额外要求 MAP 增加至少 0.005，且 MRR、Hit@10、Hit@50、MeanRecall@50 均不下降。全局推荐只从符合条件的设置中选取。
- 参数在验证前冻结；即使某个家族开发效果不佳，也保留其冻结赢家作负结果对照。验证结果不用于换参数。
- 每条报告及全部标签保留；不依赖 B 是否成功。当前来源 A 全部成功。基础设施或校验问题中止实验，不能删样本或伪装成方法失败。
- 用项目分层、报告配对 bootstrap 与随机符号检验各重复 5,000 次；对所有冻结方法的 5 个主指标一起做 Holm 校正。另检查项目宏平均、去掉任一项目、去掉最大收益样本、报告去重及截断子组。
- 20 次开发集 70/30 项目分层划分，每次只在训练部分选参数，再评估测试部分；额外做开发集逐项目留出。这些划分互相重叠，不能当作 20 个独立数据集。

开发集冻结后、查看验证指标前，再预定两组诊断，不用于重新选择主方案：

1. **机制消融**：固定主方案的候选池、聚合与权重，分别只保留标识符、只保留路径/模块、只读取向量模型实际编码过的报告正文，以及去掉全部结构分数。特别检查收益是否只是来自读到了 512-token 截断之外的文本。
2. **召回目标对照**：在原开发网格中，满足 MAP/MRR/Hit 条件的结构匹配设置按 MeanRecall@50 选出 `anchor_d200_w0.5`。它是另一个明确目标下的预先选择，不能用它的验证分数替换原 MAP 主方案的成绩。统计上额外报告将这 5 项检验并入主比较后的 30 项 Holm 校正。

原 500 条来自 9 个项目。Requests、Flask、Seaborn 共 77 条均在后续复核中，另行报告这些本轮未参与调参项目的表现；这不抹去历史实验曾观察这些项目的事实。

## 已检查的收益与退化机制

以下为开发集案例诊断，不能替代完整的统计结论：

- Matplotlib #20761：原始 A 将测试和示例排在实现前；`add_gridspec`、`add_subplot`、`subfigures`、`subplots`、`supxlabel` 等声明匹配使 `figure.py` 从第 6 升至第 1。
- Sphinx #10481：报告中的源码路径及声明线索，使 `sphinx/config.py` 从第 8 升至第 1。
- Matplotlib #24749：报告提到 `contour`，同名 API 定义使 `axes3d.py` 和 `_axes.py` 超过真正修复的 `contour.py`，其排名由第 1 降至第 3。
- Matplotlib #22734：`pyplot.py` 同时匹配 `clim`、`colorbar`、`show`、`tripcolor`，超过真正修复的 `tri/tripcolor.py`，后者从第 1 降至第 2。

这说明“找到报告提及的 API”与“找到需要修复的实现”并不完全相同。后续可研究限定名解析及包装层消歧，但本轮没有验证这些新机制，也没有依据少量退化案例再次调参。

## 论文依据与适用范围

- [BLUiR，ASE 2013](https://mattlease.com/papers/saha-ase13.pdf)：利用类名、方法名等程序结构的信息。本实验只借鉴结构证据，不声称复现完整 BLUiR。
- [An Analysis of Fusion Functions for Hybrid Retrieval](https://arxiv.org/abs/2210.11934)：分数融合与名次融合有不同性质。本实验采用归一化分数加结构证据，论文中的词法/稠密检索结论不能直接替代本项目验证。
- [Pseudo-Relevance Feedback with Dense Retrievers in Pyserini](https://hangli.me/files/adcs2022.pdf)：向量层面可实施伪相关反馈。本实验有意限制候选及块表示，是低成本先导变体。
- [BLIZZARD，FSE 2018](https://arxiv.org/abs/1808.00594)：报告结构信息的缺失与过量都可能影响检索。本轮未实现报告分类、栈图或完整查询重写。

已有切块、控制条件、作用域、重叠和调用依赖拼接实验见[切块结论](chunking-conclusions.md)，本轮没有重复投入全库切块与编码。

```bash
  scripts/experiments/run_a_improvements.py \
  --output results/a_improvements/<new-run> --workers 4

OPENBLAS_NUM_THREADS=1 .venv/bin/python \
  scripts/experiments/run_a_anchor_ablation.py \
  --run results/a_improvements/<new-run>

OPENBLAS_NUM_THREADS=1 .venv/bin/python \
  scripts/experiments/run_a_recall_control.py \
  --run results/a_improvements/<new-run>

OPENBLAS_NUM_THREADS=1 .venv/bin/python \
  scripts/analysis/analyze_a_improvements.py \
  --run results/a_improvements/<new-run>
```

输入和实现哈希变化时拒绝续跑旧目录。代码、报告和向量只读；不新增生成、Embedding 或 Reranker 调用。报告原始正文按数据集哈希校验，向量检索正文保留历史 `.strip()` 处理；不得将两者的哈希混为一谈。

主程序逐条检查完整来源结果 SHA256、样本身份、候选、修复前源码哈希、向量校验和及归一化，并从全部块分数复现历史 Max、Top-3 Mean 和 LSE(0.1) 排名。反馈的 beta=0 对照用 NumPy 复算最佳块余弦分数，误差不得超过 `2e-5`。

独立分析入口从保存的排名重新计算指标，复核冻结参数选择、验证产物时间及输入哈希。它不会替代主程序的源码/向量完整性检查。

`20261122_v1` 是正文空白处理校验失败的预检目录，未产生有效样本；`v2` 是调度改为四进程前中断的试运行。正式结论只使用 `v3`，没有按结果择优拼接不同运行。
