# 多数据集AB/C系数实验：已完成

实验目录：`results/multidata_coefficients/20261124_v1/`。已于2026-11-25 05:24（北京时间）完成，并通过独立复核。结论是SWE有改进证据、GHRB未验证出收益，尚无跨数据集统一最优系数；详见[最终结论](multidata-coefficient-results-20261125.md)。下文保留启动时的固定方案，主结果位于`analysis/`。

结构分数使用`structure_ast_v2`，参数定义为：

```
p = α N(A) + (1−α) N(B) + γ E
s = (1−β) max_chunk_logit + β joint_file_logit + λ p
```

每个报告先获得A50∪B50所有候选的结构分数、最大块分数和文件联合分数。每组参数重新构建AB Top50，再按最大块分数得到C原排序，只调整该排序前十。所有必要文件分数齐全才评价，不能用固定候选池重放代替联合实验，也不对缺失评分补零。

划分由种子20261124的项目身份哈希决定，每个数据集一半项目用于开发、一半用于验证。相同issue或规范化正文不跨划分，两个数据集之间检查正文重复。GHRB保留全部有效记录，SWE使用原历史500名单。SWE此前已参与方法开发，因此新的项目划分不能使它变成新的盲测集。

搜索网格：α、β均为0到1、步长.05；γ为0/.1/.2/.25/.3/.4/.5/.6/.75/1/1.5/2；λ为0/.25/.5/.75/1/1.5/2/3/4/5/6/8/10/12/16/24/32/64。共95,256组。目标为开发MAP@10最大化；同分优先当前系数，然后偏好较低系数总和。这是纯精度目标，不是历史实验的“限制正确首位破坏”目标。

分别选出每数据集最佳组合及一套共享组合。共享组合按两个数据集开发MAP等权求均值，不按报告数加权。另保留只调整AB、只调整C的消融。所有选择写入`analysis/frozen_choice.json`后才计算验证成绩；验证集不会重新选出所谓最佳参数。参照组合是**同一新结构特征**下的(.5,.5,.25,4)，不能直接与历史Python正则结构的已发布成绩混为同一基线。

GHRB使用新下载的修复前Java源码和原issue文本，生成新的功能查询及检索/C分数；仓库迁移通过实际GitHub重定向核验，原身份与规范身份均保留。全量压缩包保存在数据盘，检索只物化Java文件。GHRB语义检索使用精确NumPy余弦和现有Max聚合；SWE复用已核对的历史ES排序、查询与选块内容，重新计算新结构分数及候选并集上的C分数。两种检索实现可能在浮点平局附近存在差异，数据集之间不声称逐位数值一致；每个数据集的系数对照共用完全相同的保存评分。

GHRB保留新增文件及XML标签，AP分母不因其不在Java候选中而缩小。最终报告必须同时查看候选覆盖、Top50及多文件召回。功能生成超长或非法输出计为失败且保留零分；基础设施、源码完整性错误停止任务并保存状态，不删除样本。源文件大于2MiB、符号链接及配置排除目录不作为Java候选；源码解码在此独立GHRB入口采用UTF-8替换无效字节，解析恢复情况保留到结构匹配记录。

主比较为每数据集的“单独选参vs默认”和“共享选参vs默认”，共4项MAP检验，做Holm校正，同时报告逐报告配对区间与按项目整体重采样区间。MRR、Top1/5/10/50、Recall10/50和首位纠正/破坏一并保存。

## 自动执行与状态

- `scripts/datasets/prepare_ghrb_sources.py`：获取129份不同的修复前快照，记录到`datasets/GHRB_sources/`。
- `scripts/experiments/run_multidata_coefficients.py`：准备协议、GHRB生成/检索、SWE输入、新C评分，逐例保存校验和并支持继续运行。
- `scripts/experiments/continue_multidata_coefficients.py`：等待已经启动的准备任务，随后使用GPU1依次执行GHRB检索、GHRB重排、SWE重排和最终CPU选参/验证；不终止其他任务。
- `scripts/analysis/evaluate_multidata_coefficients.py`：联合搜索、冻结选择、验证、统计和Markdown报告。

控制器已以独立后台进程启动，PID与命令记录在`controller_pid.json`。阶段状态、进度、错误及日志均写入实验目录。没有运行完成前的最佳系数结论。控制器遇到失败会将状态记为`failed`并保留堆栈，不将部分数据当作完成结果。

最终产物规划：`analysis/report.md`、`summary.json`、`statistics.json`、`frozen_choice.json`、两个开发网格CSV及验证逐报告排名。
