# C500为什么改善：排名变化、信号消融与代码证据

2026-11-23。基于已完成的500条冻结结果做事后诊断，没有重新调用模型、训练或选择参数。原始组合及比较口径见[500条结果](c-evidence-prior500.md)。本分析的去信号变体只用于解释，不替换原方法。

**最有证据支持的解释是：保留文件层面的检索和名称归属信息，并用文件内联合证据修正单个高分块造成的头部误判。** 当前结果支持排序决策的改善，尚不能证明模型学会了更强的根因推理；混合选块本身的独立增益也没有因此得到确认。

## 1. 改善发生在前十内部，尤其是第二名与第一名的竞争

候选池、原前十集合及第十一名后的排序逐例不变。Hit@10=93.0%、MeanRecall@10=0.857261都不变。MAP从0.647302到0.690172、MRR从0.718317到0.765375，来源是同一批已召回文件的次序变化。

50次首位纠正中，被提到第一名的标注文件原名次为：第2名34条、第3名5条、第4名8条、第5名2条、第8名1条。也就是**34/50来自第二名，49/50来自原第2—5名**。不是从大量遗漏候选中找到新文件，而是在已经很接近的候选之间改善判断。

按最终结果分组，对总MAP变化记账如下。这里记录每组报告的完整AP差，不把它当成仅移动首位的因果效应。

| 报告组 | 条数 | 对全500条ΔMAP的贡献 |
|---|---:|---:|
| 首位从错到对 | 50 | +0.048578 |
| 首位从对到错 | 16 | −0.013869 |
| 首位保持正确 | 280 | +0.001317 |
| 首位仍不正确 | 154 | +0.006843 |
| 合计 | 500 | +0.042869 |

16条误改中，原首位正确文件有15条降到第二名、1条降到第三名。这同样表明错误主要发生在相近候选的优先级判断。

## 2. 主要收益来自初排信息，结构匹配是其中最明确的信号

原C最终按块级Max排序，A/B召回信息主要影响候选选择和同分处理。新组合显式保留：原报告语义分数A、功能推测语义分数B，以及完整报告中的名称与修复前文件声明/路径的匹配E。

E是名称匹配启发式，不是调用图或完整静态语义分析。它匹配函数/类声明而非所有词语出现位置，因此有机会区分“定义某接口的文件”和“只是调用该接口的测试”。E也来自完整报告及文件声明，信息范围与原C的截断报告和少量代码块不同，不能把这部分增益归为重排模型能力增强。

既有消融：仅初排分数修正得到0.681817，已经比原C高0.034515；联合证据再加上去到0.690172，额外增量0.008354，逐报告区间跨零。两者单独收益不能直接相加为互不重叠的贡献。

本次在**不重选权重、不改候选或证据**的条件下，把公式展开为 `0.75z + 0.25u + 2A + 2B + 2E`，分别删除信号：

| 固定权重的事后去信号诊断 | MAP@10 | 相对完整组合 | 首位纠正 / 破坏 |
|---|---:|---:|---:|
| 完整组合 | 0.690172 | — | 50 / 16 |
| 去掉原报告检索A | 0.694803 | +0.004631 | 52 / 12 |
| 去掉功能推测检索B | 0.685625 | −0.004547 | 45 / 13 |
| **去掉结构匹配E** | **0.675466** | **−0.014705** | **39 / 17** |
| 去掉A、B，只保留E与两类重排分数 | 0.678596 | −0.011576 | 40 / 13 |

完整组合相对去E的ΔMAP=+0.014705，逐报告区间[+0.006158,+0.023932]、项目整体区间[+0.003737,+0.027224]，四项探索性删除比较Holm p=0.002400。结构匹配是这组诊断里证据最明确的单项。

去A略好、去B略差的区间均跨零。原报告重排和A可能重复强化相似的表面相关性，这是一个待验证的冗余信号，不能据这次事后分析宣布应删除A。这些删除同时改变分数标度和候选竞争关系，不是完整的因果贡献分解。

实际例子：Pytest #9133要求`pytester.RunResult.assert_outcomes()`支持`deselected`。原首位是`testing/test_terminal.py`；正确的`src/_pytest/pytester.py`包含`RunResult`、`assert_outcomes`、`parseoutcomes`声明，实际输入中能看到`assert_outcomes`缺少该参数。结构匹配找到这些声明；测试文件的匹配则主要是其他检查函数。最终正确文件从第二名升到第一名。去E后，首位又回到测试文件。

## 3. 联合证据的作用：削弱“一个块很像”造成的错误优势

Max只让一个最高分块决定文件分数。联合输入把同文件已选块放在一个上下文中，提供多个证据共同描述行为的机会。当前权重只让联合分数占25%，保留原Max的75%，限制全量改写排序。

50条最终纠正中，原正确文件相对原首位的Max分数平均落后0.799；联合评分残差平均弥补0.643，初排差平均弥补1.829。这些是评分公式的算术项，不是模型置信概率，也不是全体报告上的因果贡献比例。在这50条中，46条的联合残差有利于被提升文件，46条的初排差也有利于它。

Xarray #4075是联合证据有用的例子。报告给出布尔权重导致加权平均错误，实际输入的三个块包含：

- `mean()`进入`_weighted_mean()`；
- `_sum_of_weights()`把`da.notnull()`与权重交给`_reduce()`；
- `_reduce()`使用`dot()`，结果作为加权平均的分母。

因此同一上下文能看见“入口—权重和—点积—除法”的关系。原Max把测试文件排第一，分数5.750；实现`xarray/core/weighted.py`为5.5625。联合评分分别为3.8125和6.5625，最终实现文件升到第一名。这里初排总分其实更偏向测试文件，联合证据帮助抵消了这个方向。

这与“跨块信息有帮助”的解释一致，但不能仅由分数变化断言模型进行了正确的因果推理：联合输入还改变了包装格式、重复路径前缀及数值批次，当前控制没有把这些效应单独隔离。

## 4. 两种信号既有重叠，也有协同

只看最终成功纠正的50条：

| 单项方案的表现 | 条数 |
|---|---:|
| 仅初排单项能纠正，联合证据单项不能 | 24 |
| 仅联合证据单项能纠正，初排单项不能 | 4 |
| 两个单项均能纠正 | 13 |
| **两个单项均未纠正，组合才纠正** | **9** |

Django #14725要求模型表单集支持“只编辑已有对象、禁止创建新对象”。原首位为测试表单删除行为的文件；正确的`django/forms/models.py`排第二，其实际证据包含`save_new()`、`save_new_objects()`以及遍历`extra_forms`创建对象的逻辑。

相对原首位，正确文件的Max差为−1.875。联合评分残差弥补+0.875，初排差弥补+1.105090；单独任一项都不足以反超，合计后分差为+0.105090，才升到第一名。该例提供了可复算的协同，而不仅是根据总MAP猜测。

相对“仅初排分数修正”，最终组合新增16个正确首位，同时新增7个错误首位，净增加9个。额外MAP只有0.008354，说明联合证据并非没有作用，但不少收益与原有信息重叠，也伴随新的错误。

## 5. 测试文件干扰减少，但解释依赖标签分布

50次首位纠正中，23次从测试路径转向非测试路径，27次发生在其他路径之间。原首位为测试路径的报告从57条降到45条；16次误改中也有6次反向把测试路径提到第一名。

这里使用路径启发式：目录`test/tests/testing`，或文件名`test_*`、`*_test.py`、`conftest.py`。当前500条共822个“报告—标注文件”对，只有1个符合该启发式，是`doc/en/example/nonpython/conftest.py`。因此减少测试路径占据首位，在这批标签分布下容易带来收益。这不证明模型获得了普遍的修复职责理解，也不能推出测试文件都不需要修改。

实际实现没有按测试路径扣分；这些路径类别只用于本次事后诊断。

## 6. 为什么仍然改坏16条

名称和语义相关性都不保证文件负责实际修复。Pylint #5231报告在配置里写了`load-plugins=pylint.extensions.docparams`，因此入口文件`docparams.py`获得E=1。真正应改的`_check_docs_utils.py`获得E=0，但它的实际输入中有`NumpyDocstring.re_param_line`正则，仍强制要求冒号，正对应“省略`: type`时误报”的现象。

原Max把工具实现排第一；加入先验后，配置入口和测试文件越过它，正确文件降到第三。这个例子说明需要区分报告提到的入口、配置模块与真正控制出错行为的实现。

16条误改中有10条是初排单项已经错、联合证据单项仍能保对；还有3条是两个单项各自都保住正确首位，相加后才改坏。与9条组合协同纠正相对应，简单叠加也会产生协同放大错误。补充的偏序保护在小模型组合中没有减少首位误改，不能把它当作已解决风险控制。

## 对后续C设计的含义

目前有证据支持的长进是：利用文件归属信号、整合片段证据，在原第2—5名与第一名之间改善优先级。更值得继续验证的是“报告中的实体属于调用入口还是实际执行逻辑”，并据此判断是否值得推翻原排名。固定加权和仅看分差，都尚未解决这种职责混淆。

若论文讨论C的独立贡献，应把初排信息复用、结构匹配和联合证据分别保留为控制。不能把总增益4.29个百分点全部记为混合选块或联合评分的贡献。新的权重或删除A的方案需要在其他数据上冻结验证；本次没有据诊断改参数。
