## 参数含义与范围

```
p = α N(A) + (1−α) N(B) + γ E
s = (1−β) z + β u + λ p
```

A为原报告检索、B为功能推测检索、E为多语言结构分数、z为最大块logit、u为文件联合logit。所有对比使用同一个`structure_ast_v2`及同一批保存评分。

每组系数重新选择AB Top50、构建Max C排序，再仅重排该C排序前十。默认参照(.5,.5,.25,4)使用新结构特征，不是旧Python正则结构的历史结果。α=0的共享方案仍保留A Top50进入候选并集及A参与选块，只是融合分数中A的直接权重为0。

GHRB开发MAP从0.591765提高到0.641054，验证却下降，说明这次开发选择没有在保留项目上复现收益；可解释为过拟合或项目分布差异的表现，不能把下降归因于其中某个单独系数。验证差异区间跨零，也不能宣称新组合一定更差或与默认等效。

## AB和C分开看的结果

AB单独按初排MAP选择，GHRB得到(α=.4,γ=.25)，验证初排MAP为0.468415→0.465916；SWE得到(α=.3,γ=.5)，验证为0.620233→0.622624。单看AB系数没有明显且一致的跨数据集改善。

固定AB默认、只调整C：GHRB开发选择(β=.95,λ=4)，验证完整MAP为0.550241→0.544309；SWE选择(β=.6,λ=4)，验证为0.693319→0.705339。这些是次要消融，未在原四项主比较之外追加显著性宣称。

因此联合选择的系数不能拆开称为每一个模块各自最佳，λ也必须结合β和γ判断。

## 4×初排分数是否有支持

## 建议与证据边界

统一默认暂不变更；将SWE独立选择`p=.05N(A)+.95N(B)+.4E`、`s=.3z+.7u+4p`记录为有本批项目留出证据的实验候选。共享方案在SWE更高，但在GHRB无验证收益，不把它登记为通用最优。当前默认也只应称为有历史实验与敏感性分析支持的参照配置，而非已证明最优。

下一轮若要推广统一系数，应提前固定较小候选范围和选择规则，并用未参与本轮分析的项目/数据验证。GHRB只有56条开发报告却比较95,256组，选参不稳定的风险不能忽略；重复使用已观察验证集不能增加独立验证证据。

GHRB保留全部原始生产补丁标签，包括70个新增文件和3个XML标签；它们可能不在修复前Java候选中，仍计入分母。当前issue正文也不等于修复前的历史编辑版本。这些因素限制跨数据集指标解释，但没有按模型胜负删除记录。
