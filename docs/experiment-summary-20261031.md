# 实验结果汇总

## 近期实验总览（2026-11-12）

同一冻结清单共九个项目、500 条报告（原有 180＋新增 320）。语义模型为 Qwen3-Embedding-0.6B，默认 AST64；重排模型为 Qwen3-Reranker-0.6B，无本任务微调。重排查询统一使用原报告，功能推测参与召回或代码块选择。

近期实验的结论：

1. **固定 AST64 作为基础实现。** 既有 token/DP、局部上下文和依赖拼接没有稳定收益；AST 是基线组件，当前改进重点转向查询、候选与证据块选择。
2. **语义检索和功能推测改善无重排结果。** S0 相对 L0 的 500 条 MAP 增加 0.165353；H0 相对 S0 增加 0.055444，新增 320 条仍增加 0.036577。BM25 保留为词面对照。
3. **重排贡献较大。** A 相对 S0 的 MAP 增益为 0.137054（500）和 0.128078（新增320）。B 相对 A 在 500 条增加 0.003867，但新增320下降 0.002634；不能将推测召回的无重排收益直接等同于重排后收益。
4. **主召回方向差距很小。** C1 与 D 的 MAP 差仅为 0.000116（500）和 0.000077（新增320），不足以支持推测优先稳定优于原文优先。B 与 C1 同时改变候选和选块，不能把差值只归因于召回。
5. **混合选块是本轮更有价值的信号。** 在固定 C1 候选下，C2 仅用推测选块弱于 C1；C3 保留原文 Top-1，再按推测排名去重补足最多三个块，MAP 比 C1 增加 0.009304（500）和 0.008215（新增320）。C3 比强对照 A 增加 0.012096 和 0.009433。
6. **C3 仍需独立验证。** 它是本轮已比较方法中 MAP 最高者，但新增320的 Top-10 与 C1 相同，MeanRecall@10 略低。500 条已参与连续方案选择，是开发分析集；尚未做本轮显著性检验，也未在独立数据上验证最终方案。

L0/S0/A 各 500 条成功；依赖功能推测的路线有同一条 Xarray #5662 输入超长失败，按 0 计入完整分母。L0 曾遇到 ES 分词上限，修复后 500 条完成；这与功能推测失败是不同阶段的问题。

## Requests：AST 参数与 RRF 历史实验

历史实验在相同 44 条 Requests 报告上比较 AST 字符预算 1000/1500/2000 和前缀 32/64/96。1500 字符、前缀 96 的历史结果为 MAP@10 0.6351、MRR@10 0.6636，较对应 AST64 的 0.6297/0.6526 略高；逐报告 AP 为 1 胜、42 平、1 负。见 [AST 参数结论](chunking-conclusions.md)。

另一次历史实验采用 BM25 与 AST 的文件级等权 RRF（常数 60）：AST96 单路 MAP/MRR 为 0.6351/0.6636，BM25＋AST96 为 0.5921/0.6327；Top-10 从 42/44 提升为 44/44，Top-1 从 22/44 降为 19/44。Top-10 表示至少一个标注文件命中，不代表所有标注文件均命中。历史记录与服务器重跑数值不能混为同一次实验。见 [RRF 实验](hybrid-retrieval.md#本次结果2026-10-25)。

这些 Requests 报告曾用于参数探索，不是独立留出测试集。AST96 是候选，并非已证实全局最优。
