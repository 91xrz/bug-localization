## Requests：AST 参数与 RRF 历史实验

历史实验在相同 44 条 Requests 报告上比较 AST 字符预算 1000/1500/2000 和前缀 32/64/96。1500 字符、前缀 96 的历史结果为 MAP@10 0.6351、MRR@10 0.6636，较对应 AST64 的 0.6297/0.6526 略高；逐报告 AP 为 1 胜、42 平、1 负。见 [AST 参数实验](blagent-ast.md#轻量参数对比2026-10-25)。

另一次历史实验采用 BM25 与 AST 的文件级等权 RRF（常数 60）：AST96 单路 MAP/MRR 为 0.6351/0.6636，BM25＋AST96 为 0.5921/0.6327；Top-10 从 42/44 提升为 44/44，Top-1 从 22/44 降为 19/44。Top-10 表示至少一个标注文件命中，不代表所有标注文件均命中。历史记录与服务器重跑数值不能混为同一次实验。见 [RRF 实验](hybrid-retrieval.md#本次结果2026-10-25)。

这些 Requests 报告曾用于参数探索，不是独立留出测试集。AST96 是候选，并非已证实全局最优。

## 局部上下文和其他探索

- Requests 44 条中，AST64 加控制条件的 MAP/MRR 为 0.6346/0.6635，AST64 同批对照为 0.6289/0.6521；收益由 1 条报告驱动。跨项目 44 条复核为 0.5354/0.6052，对照 AST64 为 0.5366/0.6063，未复现提升。见 [局部上下文实验](ast-local-experiment.md)。
- Requests 历史实验中，AST96 直接追加调用依赖的 MAP 从 0.6351 降至 0.6019，MRR 从 0.6636 降至 0.6270；不支持用该版本替换原 AST96。见 [依赖上下文实验](dependency-ast.md)。
- Requests 历史实验中，token 贪心和 DP 分块的 MAP 分别为 0.5495、0.5210，低于同批原 AST 的 0.6297，尽管 Top-10 覆盖略高。见 [token AST 实验](ast-token-experiment.md)。
- 历史跨项目多视角实验中，三视角等权 RRF 的 MAP/MRR 为 0.5176/0.5936，低于同批原文 BM25＋AST96 的 0.5766/0.6707；记录与上述服务器重跑各自独立，不混用数值。见 [多视角复核](report-multiview-crossproject.md)。
