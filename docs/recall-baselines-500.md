# 500 条报告的无重排对比：L0 / S0 / H0

**实验角色**：S0 为无重排主基线，H0 为功能推测查询对照，L0 为传统词面检索对照。后续方法增益主要相对 S0 和原报告召回＋重排报告，不能只相对较弱的 BM25 宣称有效。固定 500 条结果支持这一研究定位，不支持“BM25 已无法作为基线”的普遍结论。为保留来源指纹，既有脚本、配置和结果目录中的 `baseline` 命名不改动。

固定使用 `configs/experiments/selections/crossproject_500_seed20261111.json`，不重新抽样。配置为 `configs/experiments/recall_baselines500.json`。

| 组别 | 查询 | 召回 | 重排 |
| --- | --- | --- | --- |
| L0 | 原始报告正文 | 文件级 Elasticsearch BM25 | 无 |
| S0 | 原始报告正文 | Qwen3-Embedding-0.6B，AST64，文件 Max 聚合 | 无 |
| H0 | Qwen3-8B 直接功能推测 | Qwen3-Embedding-0.6B，AST64，文件 Max 聚合 | 无 |

S0/H0 复用[已完成的 500 条实验](semantic-reranking-500.md)的第一阶段检索结果，逐条校验样本身份、标签、候选路径，并从完整文件排名复算 @10 指标。H0 已有的 Xarray #5662 生成失败保留，按 0 计入完整分母。

L0 使用相同修复前快照、候选文件及内容哈希。沿用既有 BM25 配置：k1=1.2、b=0.75，代码标识符分析器、最多 512 个去重查询词，按分数降序／文件路径升序打破平局。查询不加入功能推测或标签。BM25 按其词项上限截断，语义路线沿用原编码器截断规则；不声称两者使用完全相同的截断长度。

全部 500、新增 320、原有 180 分别汇总 MAP@10、MRR@10、Top-1/5/10、MeanRecall@10，并输出分项目指标。L0 未跑完时不发布其最终指标。基础设施或一致性异常会停止执行，修复后用同一命令恢复；已完成结果重新核验并复用。输入、源结果或实现指纹改变时拒绝继续写入原目录。

```bash

  --output results/recall_baselines/20261112_L0_S0_H0_500 --check-only
.venv/bin/python -u scripts/experiments/run_recall_baselines500.py \
  --output results/recall_baselines/20261112_L0_S0_H0_500
```

2026-11-12 已启动，后台会话 `irbl-recall-baselines500`。日志是输出目录中的 `run.log`。每条报告保存 `L0/NNN/result.json`，并更新 `samples.json`、`final_summary.json`、`comparison.csv`、`project_summary.json`。完成后写入 `verification.json`。保留所有预先存在的 ES 索引，仅清理当前样本新建且所有权核验通过的 BM25 索引。

### 结果解读

合计 500 条上，S0 相对 L0 的 MAP@10 增加 0.165353（相对 +49.85%），Top-1 提高 12.00 个百分点。H0 相对 S0 的 MAP@10 再增加 0.055444（相对 +11.15%），Top-1 提高 10.00 个百分点（186 → 236 条），Top-10 提高 4.00 个百分点（432 → 452 条）。逐报告 AP，S0 对 L0 为 265 胜、123 平、112 负；H0 对 S0 为 191 胜、200 平、109 负。

新增 320 条上，H0 相对 S0 的 MAP 增益为 0.036577（相对 +7.09%），低于原有 180 条的 0.088986（相对 +19.20%），但总体正向收益仍然存在。合计 500 条的九个项目均满足 H0 > S0 > L0（按项目 MAP）；新增 320 条中，H0 在七个项目的 MAP 高于 S0，在 Matplotlib、pytest 上下降。

本次固定样本的无重排对比支持：语义检索整体优于 BM25，功能推测进一步提高无重排效果；收益存在项目差异，且新增样本上的提升幅度较小。未做显著性检验。这不改变此前重排实验的结论：在重排后，功能推测的额外 MAP 收益在新增 320 条上并未复现。
