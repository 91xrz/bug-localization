# C 的主动证据核查：首位分歧实验

## 实验协议

清单为之前讨论的第二轮 LoRA SWE90（9 项目各 10 条），不根据 C3、BLAgent、8B 的表现或分歧重新抽样。该批历史结果已被用于立项，不能称为全新盲测。推理不使用修改标签、补丁、修复后代码或 BLAgent 排名。不改变 A/B 检索。各方法统一在全部 90 条上按全部修改文件计算 @10 指标。

1. 在相同的 C3 候选与原始证据上，按已有普通 Qwen3-8B BF16 前十联合重排协议重新推理，得到共同起点；无合法排列则按已有协议计零。0.6B 的第一名与联合重排第一名相同就保持原样。
2. 对首位分歧的两文件按路径字母顺序呈现，不告知是哪个模型的首选。规划器看到完整报告、这两份文件原有的 C3 块和可用源码位置，为两者提出一个区分性问题，并为每个文件选一个查证位置。菜单包含本文件的相关函数/类和标识符引用附近的窗口。仅静态读取修复前快照，不执行源码；本轮没有跨文件调用图，也没有多轮自由搜索。
3. 固定组对每个文件取按报告词面匹配最强的源码窗口（无匹配时按冻结规则回退）。主动组依照规划器的选择读取。两组共享同一问题、规划器调用、候选、模型、裁决提示、每文件最多 384 个新增源码 tokens 的预算；使用真实整行和相同行号包装。每臂至多两次源码读取，一次规划和一次裁决；物理上只执行一份共享规划，报告逻辑成本时向两组各计一次。实际输入 tokens 可不同。
4. 裁决可选 A、B 或放弃。支持改排须提供两处有效行号，且至少一处引用的源码文本不在该文件原始证据中，否则保留联合排名。支持另一文件时将该文件提到首位，其余相对顺序不变。程序核验引用的真实性及逐行新颖性，不能据此认定语义判断正确。复核阶段的格式/上下文失败是已定义的弃权，不把基础设施错误作为算法输出。
5. 主要比较主动减固定的逐报告 AP@10；另比较普通联合重排和本地 BLAgent 8B。报告项目内配对 bootstrap 区间（10,000 次）、首位纠正/损害、调用量和实际 tokens，不把本地结果外推为超过原论文模型。普通与两证据组共享候选和前十集合，除失败外 Top-10 集合不变，此实验不能补救原前十未召回。

## 实测结果

| 方法 | MAP@10 | MRR@10 | Top-1 | Top-10 |
|---|---:|---:|---:|---:|
| 原 C3（参照） | 0.646790 | 0.715970 | 51/90 | 86/90 |
| 普通 8B 联合重排 | 0.746384 | 0.812593 | 64/90 | 85/90 |
| 分歧时固定补证据 | 0.739903 | 0.805185 | 63/90 | 85/90 |
| 分歧时主动选证据 | 0.753792 | 0.820000 | 65/90 | 85/90 |
| 本地 BLAgent 8B | 0.774953 | 0.842901 | 69/90 | 86/90 |

88 条有合法初排，52 条首位一致不触发，36 条进入核查。2 条初排失败（三组均计零）：Sphinx #10067 耗尽输出预算，SymPy #18744 未返回合法排列。基线 C3 和本地 BLAgent 由历史同批预测独立复算。评估器复核了每个被检查窗口的真实源文件、行段和每次排序更新。

- 主要比较，主动减固定：ΔMAP **+0.013889**，按项目内配对重采样 95% 区间 **[−0.005556,+0.037963]**，逐报告 AP 为 4 胜、85 平、1 负。主动与固定组在 35/36 条上至少读取了一段不同的源码，但排名没有普遍改变。
- 主动减普通：+0.007407 [−0.016667,+0.033333]，纠正 3 个首位、损失 2 个。主动减本地 BLAgent：−0.021161 [−0.074025,+0.031077]。本轮不支持声称主动策略稳定领先固定策略或超过 BLAgent。
- 主动组 36 次核查中：6 次提升另一个文件，7 次以有效引用确认原首位，13 次引用无效、10 次未引用新增行，后两者均保留原排名。“有效”只表示通过程序的行号与新颖性规则。若事后用标签在允许的两个动作中总选 AP 较高者，整批 MAP 上限为 0.785314，只比本地 BLAgent 高 0.010361；这是受本轮触发、候选与更新方式限制的理论上限。
- 普通 8B 阶段 110 次真实生成调用；每个核查方案逻辑上再加 36 次计划、36 次裁决，共 182 次。固定/主动逻辑总输入分别为 1,202,689 / 1,201,956 tokens，总输出为 39,211 / 39,397，不含 A/B 上游。两组物理复用了同一批规划。该对照测的是“同一规划问题下谁选哪段证据更好”，不是独立的无规划词法系统的最低成本。

**Django #16333 逐例核对**：普通 8B 已经从原 C3 的 `django/forms/models.py` 改为标注文件 `django/contrib/auth/forms.py`，两组均保留正确首位。但主动组提问的是 `UserCreationForm.save`，引用的 A:310 却属于 `PasswordResetForm.save`，B:776 属于 `BaseModelFormSet.save` 中的局部函数，而非 `BaseModelForm.save`。说明“路径正确、行真实”不等于“验证了正确的对象”。此例不计作 Agent 找回的首位。[真实规划与裁决](../results/c_agent90/round1/review/cases/0251/result.json)

**决定**：不替换默认 C3，也不在这 90 条上继续试阈值。下一轮优先把工具选项改为可核验的类/方法限定名，把自由填写的行号改成从已返回的证据片段 ID 中选择；分别核对“查对对象”和“确实改善排序”。若只在两首选之间改排，要同时关注上述上限。扩大候选是另一个实验因素，不能与工具修复混在同一消融中。
