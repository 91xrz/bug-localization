# 近期实验汇总（2026 年 11 月 9–14 日）

本轮研究从 AST 分块与报告补全，逐步收敛到直接功能推测、双路候选和代码证据重排。当前最明确的结果是：语义检索优于本项目 BM25 对照，直接功能推测改善无重排检索，重排带来最大的后续收益；混合选块的额外收益仍待独立验证。

## C3 的收益、统计与成本

C3 在混合候选池内先选原文 Top-1，再按推测相似度补足至最多 3 个不同代码块；重排查询仍使用原始报告，文件得分取块分数最大值。功能推测不直接送入重排器。

500 条上，C3 相对原报告召回＋重排的 ΔMAP 为 **+0.012096**，AP 胜/平/负为 77/382/41。按项目重采样 95% 区间为 **[-0.001422, 0.024826]**，Holm 校正 p=1.0000，不能宣称总体改善显著。2×2 消融的点估计更支持选块贡献，但选块效应区间同样跨零。

LCA Python 排除 3 条历史报告后，固定 47 条两组均成功：原报告路线 MAP=0.5606，C3=0.5748；ΔMAP=+0.014163，项目重采样区间 [-0.024046, 0.068895]，仍不足以确认推广收益。

9 条报告各重复 3 次的端到端测量中，原报告路线均值 3.535 秒，C3 为 10.539 秒，约 **2.98 倍**。计时已预备代码向量和索引，关闭生成与查询向量缓存，不含模型加载及共享代码准备。这是研究流水线测量，不是冷启动全成本。详见[补充实验结果与原始记录](c3-supplement-results.md)。

## 最新融合诊断意味着什么

模块消融 A+B 沿用原文排名，仅合并候选集合；499 条共同成功样本的 Top-10 与 S0 完全相同。完整分母 MAP=0.496395，比 S0 低的差异全来自那条推测失败。若改用推测优先插入顺序，Top-10 又会等同 H0。因此需要显式的融合排序规则，才能检验两路互补是否改善无重排排名。

45 条 CPU 小批中，H0 MAP=0.520309，等权 RRF（k=60）为 **0.572392**，增加 0.052083，AP 为 13 胜、25 平、7 负。完整集合和固定 50 文件池的逐报告 @10 指标一致。旧 180 条上同一 RRF 却低于 H0，说明效果随样本变化。这 45 条来自已观察的开发数据，只作为继续验证的信号，不是独立测试或显著性结论。见[固定方案、全部规则与核验](fusion-pilot45.md)。
